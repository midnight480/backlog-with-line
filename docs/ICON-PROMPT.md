# Bot アイコン生成プロンプト（Nano Banana 2 / Gemini 画像生成用）

LINE公式アカウントのアイコンはトーク一覧・グループメンバー欄に**小さな円形**で表示されます。中央にモチーフを置き、端に十分な余白を持たせた構図にしてください。

## メインプロンプト

```text
LINE公式アカウントのアイコン画像を生成してください。

コンセプト：Backlog（課題管理ツール）と連携する、LINEグループ内の作業ボット。
- 中央に配置したフレンドリーなロボットの頭部のマスコット
- ロボットが小さなタスクカード（チェックリスト付きのカンバンカード）を持っている
- 背景はLINEらしいグリーン（#06C755）または濃いネイビーに緑のアクセント
- フラットデザイン、太めの輪郭線、シンプルな形状
- 正方形1:1、円形にトリミングされる前提で上下左右に余白
- 文字・ロゴ・透かしは入れない
- 小さく縮小しても輪郭が判別できるレベルの単純さ
```

## バリエーション

**A. 吹き出し + チケット型（連携のイメージを強調）**

```text
チャットボット用のアイコンを生成してください。緑色の吹き出しの中に
白いチケット（課題カード）のアイコンがあり、カードにはチェックマークと
短い横線が2本。背景は単色グリーン #06C755、フラットでミニマルな
ピクトグラム風デザイン。正方形、円形トリミングに耐える中央配置と余白。
文字は入れない。
```

**B. ロボット + 矢印ループ型（双方向連携のイメージ）**

```text
LINEのボットアイコンを生成してください。丸いフォルムのロボットの顔の
両側に、往復を表す2つの曲線矢印（LINEの吹き出しとタスクカードの間を
つなぐイメージ）。配色はグリーン #06C755 とホワイト、濃紺のアクセント。
モダンなフラットアイコン、1:1正方形、中央配置、余白あり、文字なし。
```

## 生成時のコツ

- アスペクト比 **1:1（1024×1024）** で生成
- 生成後、円形にクロップしたプレビューで四隅が欠けないか確認
- 気に入った構成が出たら「背景色を #06C755 に」「ロボットを正面に」など部分修正指示で詰める
- 文字を入れたくなるが、小サイズ表示で潰れるので入れないのが無難

## 設定場所

LINE Official Account Manager（https://account.line.biz/）→ 対象アカウント → 設定 → アカウント設定 → プロフィール画像
